# AI Resume Analyzer
## Project Description

AI Resume Analyzer is a Python-based web application that analyzes PDF resumes and compares candidate skills with job descriptions.

## Features
Upload PDF resumes
Extract resume text
Identify candidate skills
Compare skills with job requirements
Calculate matching percentage
Identify missing skills
Generate improvement suggestions
Technologies Used
Python
Gradio
PyPDF2
Regular Expressions
Google Colab
How to Run
Open Google Colab.
Install Gradio and PyPDF2.
Copy the Python source code from app.py.
Run the code in Google Colab.
Upload a PDF resume.
Enter a job description.
Click Analyze My Resume.
